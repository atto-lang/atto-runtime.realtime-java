# 2026-11-11 audit and hardening

## Scope and evidence

Scope: `atto-poc/atto-nats-clone.atto` Core NATS wire/subject oracle,
JetStream actor state skeletons, queue-group routing model, WAL framing and
proposed Raft commit gates.

The independent Rust tests are executable specification models and protocol
parser tests. **They are not the server.** No real Atto guest compiler run,
TCP listener, NATS official-client interoperability, native AOT, durable stream,
or three-node Raft consensus is established by passing Rust CI.

## Findings and fixes

1. **P0 fail-open parser.** The Rust decoder emitted any unknown control
   line, including server-only INFO/MSG and arbitrary text, as an accepted
   control frame. Validate client command grammar for PING, PONG, CONNECT,
   SUB, UNSUB and PUB/HPUB; reject unknown or malformed commands; poison
   the connection decoder on any framing error. The CONNECT JSON is
   intentionally not yet parsed/authorized: a real adapter must parse it
   with a typed decoder and enforce auth before processing subsequent
   commands.
2. **P0 consumer ACK floor could skip holes.** Source actor accepted an ACK
   sequence larger than the floor without proving it was pending. Fail
   closed to one outstanding delivery in the Atto scaffold. A bounded Rust
   multi-flight state-machine model checks out-of-order ACK holes,
   unsolicited/duplicate ACKs, redelivery, generation changes and backpressure.
   Persistent sparse-ACK and consumer state still require implementation.
3. **P0 quorum/witness not implemented.** A Rust AppendGate model now rejects
   insufficient voter counts, stale terms and simultaneous reservations.
   A vote COUNT is NOT a cryptographically / replication-verified quorum
   certificate. Real Raft must verify distinct follower identities, entries,
   terms, fsync and membership epochs. Atto `RaftGroupActor` remains an
   intentionally inactive skeleton; never claim the model itself commits data.
4. **P1 subject routing model.** Queue-group load balancing must consider only
   matching live subscriptions, not all members of a group on other subjects.
   A Rust RouterModel now tests wildcard groups, ordinary fan-out,
   unsubscribe and bounded uniqueness. Real Atto trie and connection
   fan-out remain open.
5. **P1 actor WAL completion accounting.** Completion previously incremented
   without proving admission; the Atto source now refuses unsolicited or
   duplicate completion and seals admission on retirement. No file I/O or
   durable fsync is implemented.
6. **P1 WAL recovery framing.** Rust tests now enumerate every possible
   truncated final-frame byte offset, complete-record CRC corruption,
   binary data and append prefix recovery. The framing model is not a WAL
   persistence engine or crash-safe checkpoint implementation.

## Release blockers

- Compile and execute source `state{}` / `critical` / `handle_state` on
  a pinned real Atto compiler, with diagnostic/evidence receipts.
- Implement authenticated, bounded raw TCP accept/read/write on the source
  actors, and reject all unknown commands and failed CONNECT authentication.
- Drive official NATS clients against this server, not just the Rust oracle.
- Persist WAL to disk, exclusive process leases, fsync boundaries, snapshots,
  consumer cursor restoration and fail-closed corruption handling.
- Verified 3-node Raft with per-peer durable replication and majority quorum.
- TLS/permissions/accounts/quota enforcement, cancellation/drain and native AOT.
- Do not merge into a production release or open public ports without these.

## CI evidence rules

Pass `cargo fmt --check`, `cargo test --locked`, `cargo clippy -D warnings`;
record exact repo SHA and test counts. Scope as `RUST_REFERENCE_ONLY`.
Nonzero executed CI steps are mandatory; an empty steps list means runner
admission failure, not a compile/test pass.
